# homeserver
Personal home server configuration

## Requirements

- [Docker for compose](https://docs.docker.com/engine/install/)
- [git-crypt](https://github.com/AGWA/git-crypt)
- Paste git-crypt `key` file at repository root

## Usage

Start services
```shell
sh homeserver.sh up
```

Stop services
```shell
sh homeserver.sh down
```
